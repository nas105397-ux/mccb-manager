# コードスタイル

このプロジェクトでは、表記ゆれを減らすために ESLint と EditorConfig で基本ルールを揃えます。

## 基本方針

- インデントはスペース 2 つ。
- JS/JSX の文字列は double quote を基本にする。
- 文末にはセミコロンを付ける。
- 複数行の配列・オブジェクト・引数には末尾カンマを付ける。
- ファイル末尾には改行を入れる。
- 行末スペースと過剰な空行は残さない。

## 確認コマンド

```bash
npm run lint
```

自動修正できる表記ゆれは次で整えます。

```bash
npm run lint:fix
```
